Loan Default Risk Analysis | Power BI

Project Overview

This project explores loan default patterns and borrower risk characteristics using Power BI. The objective is to analyse loan portfolio performance and identify patterns associated with loan defaults.

Business Objective

- Analyse overall loan portfolio performance.
- Understand loan default rates across borrower categories.
- Explore the relationship between financial indicators and loan defaults.
- Identify borrower segments with relatively higher default rates.

Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization

Dataset Overview

- Total records: 255,347
- Total features: 18 original columns, with additional derived analytical columns.
- Target variable: Default (1 = Default, 0 = No Default).

Dashboard Pages

1. Loan Portfolio Overview

Provides an overview of total loans, defaulted loans, default rate and loan distribution by purpose and credit score band.

2. Borrower Risk Analysis

Explores default patterns across:

- Employment type
- Marital status
- Education level
- Age groups
- Dependent status

3. Financial Risk Analysis

Examines default patterns across:

- Loan amount groups
- Debt-to-income ratio
- Income groups
- Co-signer status

Key Findings

- Overall default rate: approximately 11.61%.
- Unemployed borrowers show a higher observed default rate than other employment categories.
- The youngest age group shows a higher observed default rate than older age groups.
- Higher loan amount groups show different default patterns from lower loan amount groups.

These findings describe associations in the dataset and should not be interpreted as proof of causation.
